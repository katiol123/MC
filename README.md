# BONEFORGE — процедурный 2D-файтинг

Аркадный файтинг «улица на пирсе» с шестнадцатью бойцами. **Все бойцы и вся их анимация рисуются кодом**:
скелет с иерархией костей → прямая/обратная кинематика → процедурная геометрия тела (мышечные
сегменты на кривых Безье, торс, череп, одежда), cel-shading с контровым светом, контуры, тени.
Ни одного спрайта, sprite sheet или растровой картинки бойца в бою не используется.

Портреты из `assets/portraits/` (присланные концепты) показываются **только** в меню: на экране
выбора бойца, VS-заставке, в иконках HUD и на экране победы. Внешность процедурных бойцов
(причёски, одежда, палитра) сделана по мотивам этих концептов. Музыка боя — присланный трек
`assets/music/steel-tangerines.mp3`; звуковые эффекты синтезируются WebAudio.

## Запуск

**Самый простой способ — открыть `index.html` двойным кликом.** Он подключает `boneforge.bundle.js`:
все модули из `src/`, собранные в один обычный скрипт, поэтому игре не нужен сервер (портреты,
музыка и настройки работают и из `file://`).

Для разработки (Node.js ≥ 18, зависимостей нет):

```bash
npm start            # локальный сервер → http://localhost:8080 (index.html) или /dev.html
npm run build        # пересобрать boneforge.bundle.js после правок в src/
```

`dev.html` грузит ES-модули из `src/` напрямую: правки видны без пересборки, но нужен сервер —
браузеры не загружают ES-модули из `file://`. `npm test` проверяет и то, что бандл не устарел.

Быстрые ссылки для разработки:
`index.html#fight=brick:jax:cpu` (сразу бой; режимы `cpu`, `versus`, `training`, `watch`),
`#select=versus`, а также `tools/gallery.html` — крупный просмотр бойцов и поз
(`tools/gallery.html#fighter=roxy&clips=idle,attack:hk,attack:s3&scale=1.4`).

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение / прыжок / присед | W A S D | стрелки |
| Лёгкий / тяжёлый удар рукой | F / G | I / O (Num4 / Num5) |
| Лёгкий / тяжёлый удар ногой | V / B | K / L (Num1 / Num2) |
| Смена стойки (ведущая рука/нога) | R | P (Num0) |
| Покрасоваться (противник оглушён) | H | ; (Num3) |

* Блок — держать «назад» (от противника); низкий блок — «вниз-назад». Удары с прыжка — overhead
  (их нельзя блокировать сидя), подсечки/лоу-кики — только сидя.
* Рывок — двойное «вперёд» (удерживать → бег), отскок — двойное «назад».
* Приседая: **↓+HP — апперкот** (лаунчер), ↓+LK — лоу-кик, ↓+HK — подсечка (нокдаун).
* Спецприёмы: **↓↘→ + удар рукой** — Surge Fist (рывок-удар), **→↓↘ + рука** — Skybreaker
  (неуязвимый взлетающий апперкот), **↓↙← + нога** — Whirl Kick (разворот, нокдаун).
* **Бросок** — LP+LK вместе (F+V) вплотную: не блокируется. **Тех** — то же сочетание в первые
  9 кадров после захвата: бросок срывается, урона нет. Нельзя бросить противника в прыжке,
  в оглушении/блоке и сразу после подъёма. Удерживая «назад», бросаешь за спину.
* **Фирменный приём** — ↓↙← + рука, у каждого свой (см. ниже).
* **Супер** — ↓↘→↓↘→ + рука, только при полной шкале (внизу экрана). Стоп-кадр с портретом,
  серия ударов. Защита от спама: супер стоит всю шкалу, сам шкалу не копит, и 8 секунд после
  него шкала не растёт; полная шкала ≈ нанести 1000 урона — реально ~1 супер за раунд.
* Комбо: лёгкие удары отменяются в более тяжёлые, обычные — в спецприёмы, **только при попадании или блоке**.
* Отладка: **F1** (или `) — оверлей, **F2** — замедление ×1/×0.5/×0.25/×0.1, **F3** — пауза,
  **F4** — шаг на один тик, **Esc** — пауза-меню. В тренировке **T** меняет поведение манекена
  (стоит / сидит / блокирует всё / прыгает / CPU).

## Красование на публику (showboat)

Пока противник оглушён (DIZZY), вместо бесплатного комбо можно сыграть на публику: у каждого из 16 бойцов
своя сценка на **1,5 секунды** (90 кадров; код и позы: `src/data/taunts.js`). Брик играет бицепсами, Раттиган
снимает цилиндр и кланяется, Смайлс хохочет, держась за живот, Джакс играет на воздушной гитаре, Велларо
поправляет воротник и целует пальцы, Рокси топает и трясёт «козой», Бруно точит нож, Ягуар приветствует солнце,
Синдер зажигает кулак и сдувает пламя, Гризз рычит на зал, Хоук встаёт в стойку журавля, Тао кланяется и
манит рукой, Горо дважды топает в сико, Собби рыдает в ладони и кричит «та-да!», Снэппер щёлкает
руками-челюстями, Чуй играет на гитаре и кричит «¡Ay ay ay!».

- **Риск.** Оглушение длится 110 кадров, сценка 90. Если начать поздно, противник очнётся посреди шоу.
  Красуясь, боец не блокирует, а **любой удар по нему засчитывается как контр-удар**: «HUMBLED!».
  Обидчик получает очки зрелищности.
- **Награда.** Доведённая до конца сценка: «SHOWBOAT!», рёв толпы, +25 к шкале супера и **15 очков
  зрелищности** (в турнире это слава). Наказать красующегося: 8 очков.
- **CPU** решает один раз за каждое оглушение соперника. Шанс выше при большом отрыве по здоровью и при высокой
  морали, выше у агрессивных и ниже у хитрых (`showboatChance`, `SHOWBOAT` в `src/ai/aiController.js`).
  Перед стартом CPU смакует момент 5–65 кадров, поэтому иногда стартует слишком поздно. Оглушённый CPU,
  очнувшись, сразу бьёт красующегося. Замер на 8 турнирах (960 матчей): CPU красуется при 36 % оглушений
  (~0,3 раза за матч), **30 % попыток наказываются**. Экономика турнира от этого почти не меняется:
  за турнир заработано 32,8 тыс. славы против 32,1 тыс. без красования, сдвиг характеристик лиги 0,0 %.

- **Звуки.** Записанные звуки лежат в `assets/sfx` и подключены через таблицу `SAMPLES` в `src/audio/audio.js`:
  рык (Гризз), хохот (Смайлс), всхлипы (Собби), аккорд гитары (Чуй, Джакс, Рокси), нож (Бруно), щелчок
  челюстей (Снэппер), рёв толпы («SHOWBOAT!») и смех толпы («HUMBLED!»). Они играют через `<audio>` и поэтому
  работают и из `file://`. Пока файл не загрузился, звучит синтезированный вариант.
  В фаталити записанные звуки озвучивают взрывы, свист, грохот, «бойнг», глухие удары, хлопки, обвал, «дзынь»,
  всплеск, монеты, электрический разряд, лопнувшую струну, храп, поцелуй и огонь. Синтезированными остались звон
  сковороды и сердцебиение.

## FINISH HIM и фаталити

В решающем раунде (тот, проигрыш в котором проигрывает матч) смертельный удар не роняет бойца, а оставляет
его шататься: «FINISH HIM!» / «FINISH HER!». У победителя 5 секунд: вплотную ввести **↓ ↘ → ↓ ↘ → + удар ногой** —
и начнётся фаталити. Обычный удар в это время — простой K.O.; если ничего не делать, проигравший падает сам.
CPU сейчас делает фаталити **всегда** (`AI_FATALITY_CHANCE` в `src/ai/aiController.js`).

**Режиссура** (`src/fatality/cinema.js`). Поверх каждого сценария работает отдельная «режиссёрская» дорожка:
- **общее для всех сцен:** кадр уходит в широкий формат (чёрные полосы сверху и снизу), интерфейс боя
  прячется, по краям виньетка; в верхней полосе титр как в кино: «ИМЯ БОЙЦА in “НАЗВАНИЕ”»;
- **у каждой сцены свои пометки, привязанные к её тикам:**
  - **субтитры** в нижней полосе с эффектом печатной машинки: «Ten thousand repetitions...» → «...for one inch.»;
  - **замедление** перед кульминацией;
  - **стоп-кадр** в момент удара;
  - **кадр удара:** мир вспыхивает одним цветом, бойцы становятся чёрными силуэтами;
  - **линии скорости**, как в манге;
  - **наезд камеры**;
  - **цветокор:** нуарная сепия у Велларо, ночной синий у спящего соперника Гризза, болотный зелёный у Снэппера;
  - **прожектор** на герое;
  - **лучи солнца** у Ягуара.

Замедление и стоп-кадры только удерживают картинку, а сам сценарий идёт тик за тиком и остаётся
детерминированным. Сцена из-за них длится на 0,5–1 секунды дольше; `extraFrames(id)` считает добавку.

**Критическое здоровье** (ниже 30 %): боец тяжело дышит (плечи ходят, голова и guard опускаются), под глазом
синяк, на брови ссадина, капает пот, и у каждого с анимацией слетает своя деталь — у Бруно колпак, у Раттигана
цилиндр, у Джакса наушники, у Ягуара маска, у Гриззли медвежий капюшон, у Хоука перья, у Брика вылетает зуб,
у Смайлса пуговицы (и открываются глаза), у Веларо расчёска, у Тао развязывается и улетает пояс (кимоно распахивается), а Синдер начинает дымиться; у Собби слетает клетчатая кепка, у Чуя улетает сомбреро (у Рокси слетает серьга-кольцо; у Горо и Снаппера ничего не слетает — только общие признаки усталости).
Предметы кувыркаются, отскакивают от пола и лежат там до конца раунда. Головные уборы, маска, капюшон, перья, наушники и серьга
рисуются тем же кодом, что и на бойце (`FighterPainter.drawDetached`), поэтому слетевшая вещь выглядит точь-в-точь как на нём.

Огонь виден только на фирменном приёме и супере Синдера; его обычные удары — без огня.

Суперы оставляют следы до конца раунда: Синдер — обугленные края одежды с тлеющей кромкой и прожжёнными
дырками, Бруно — шишку на макушке (шапки и капюшоны приподнимаются на ней), Брик — фингал на весь глаз, который
больше не открывается, Рокси — пыльные отпечатки подошв на корпусе (по одному за каждый удар, до трёх), Веларо —
перекошенный мятый воротник. Каждый удар когтями в супере Гриззли оставляет на туловище соперника набор из трёх красных царапин (до трёх наборов); они двигаются вместе с телом и остаются до конца раунда.

Все они описаны данными в `src/data/signatures.js` (шаги серий, снаряды, захваты, контр-стойка,
прыжки) — системы общие, кода «под конкретного бойца» нет.

## Характеристики бойцов

10 шкал, все реально влияют на бой. Начало и конец каждой шкалы — минимум и максимум параметра среди всех бойцов.

**Тело** (видно всегда): СИЛА — средний урон атак · СКОРОСТЬ АТАКИ — средний start-up обычных ударов ·
ПОДВИЖНОСТЬ — скорость ходьбы (бег, рывок, прыжок, подъём с пола и приземление масштабируются от неё) ·
ЗДОРОВЬЕ · СТОЙКОСТЬ — сколько стан-урона нужно до головокружения. Вес, рост, размер хитбоксов скрыты.

**Характер** (только в режиме CPU vs CPU): РЕАКЦИЯ — задержка восприятия и частота блоков · АГРЕССИЯ ·
КОМБО — продолжение комбо и наказание промахов · АНТИ-ЭЙР — сбивание прыжков · ХИТРОСТЬ — броски,
выход из бросков, своевременные спецприёмы.

У каждого бойца в `src/data/fighters.js` есть `profile` (0..1 по каждой шкале); `src/data/attributes.js`
переводит его в значения по откалиброванным диапазонам `ATTR_RANGES` и кривым поведения ИИ `AI_CURVES`.

**Калибровка** (`tools/calibrate.mjs`): зеркальные бои, где у одного бойца шкала на максимуме, у другого на
минимуме, остальное одинаковое. 600 матчей на шкалу:

| Шкала | Победы max vs min |
|---|---|
| сила | 57.8 % |
| скорость атаки | 59.7 % |
| подвижность | 59.2 % |
| здоровье | 58.7 % |
| стойкость | 59.0 % |
| реакция | 58.8 % |
| агрессия | 57.2 % |
| комбо | 59.2 % |
| анти-эйр | 57.2 % |
| хитрость | 57.5 % |

Все в пределах погрешности (±2) от ~58.5 %, т.е. полная шкала даёт ≈ +8.5 п.п. к шансу выиграть матч,
каждая десятая шкалы ≈ +0.85 п.п. Общий уровень задан самыми «слабыми» по природе шкалами
(подвижность и анти-эйр выше ~59 % не поднимаются), остальные подогнаны под них.

**Баланс ростера** (`tools/roster.mjs`, каждый с каждым, CPU vs CPU): все 16 бойцов в пределах 45–55 %
побед (2400 матчей; разброс на уровне статистического шума). Различия наборов приёмов компенсированы
профилями (у слабого набора шкалы выше), а Бруно получил броню на тяжёлых ударах — огромное тело
делает его лёгкой мишенью. `node tools/roster.mjs 8 normal '{"id":"bruno","o":{...}}'` — один боец
против всех с экспериментальными правками.

## Турнир (каждый с каждым)

Главное меню → **Tournament**. 16 бойцов, 15 туров по 8 матчей, всего 120 матчей до двух побед в раундах.
Любой матч можно **смотреть** (бой на экране) или **досчитать** в фоне: «Simulate match / round / all».
Весь турнир досчитывается примерно за минуту. Из просмотра можно выйти через паузу: «Skip to result».
Прогресс сохраняется в браузере, турнир продолжается после перезапуска.

- **Таблица:** очки (2:0 — 3, 2:1 — 2, поражение 1:2 — 1), сыграно, победы, поражения, разница раундов,
  форма по последним 5 матчам, слава. Тай-брейки: очки → личная встреча → разница раундов → нанесённый урон
  → «перфекты».
- **Расписание** показывает текущее место бойцов в таблице в скобках: «CINDER (3)  vs  (5) VOLTA».
- **Графики** (кнопка 📈 CHARTS или C): место в таблице, баланс славы, заработанная слава, показатель характеристик
  (средняя шкала с прокачкой и травмами), мораль, выносливость — по турам. Можно выбрать любых бойцов (или всех):
  у каждого свой цвет и форма маркера, совпадающие значения разведены небольшим сдвигом, наведение подсвечивает
  линию и показывает значения всех выбранных бойцов в этом туре.
- **После наград тура** — окно «Training camp spending»: кто на что потратил славу в лагере и сколько осталось
  (или «spent nothing»).
- **Карточка бойца:** клик по любому имени в турнире (таблица, расписание, сетка, награды, лагерь, отчёт после
  боя, чемпион) открывает карточку (`src/ui/fighterCard.js`). В ней:
  - место, очки, победы и поражения, слава: текущая, заработано, потрачено;
  - выносливость и мораль: насколько они сдвигают полоски тела и характера;
  - активные травмы и постоянный урон от них;
  - 10 характеристик: полоска «база → сейчас». Клик по названию раскрывает подробное объяснение, на что влияет
    характеристика, и расклад текущего значения: база, улучшения, урон от травм, активные травмы, выносливость или
    мораль, итог;
  - фирменный приём и супер с вводом и описанием (описания: `src/data/moveInfo.js`);
  - все матчи турнира: счёт, слава, фаталити, травмы, hype, андердог, красование. Клик по строке запускает повтор,
    клик по сопернику открывает его карточку;
  - награды туров;
  - история покупок по лагерям, с пометкой, кто купил: менеджер или игрок.

  Esc или клик мимо карточки её закрывает.
- **Сетка результатов** (G): матрица 16×16; клик по счёту — **повтор** этого матча. Симуляция детерминирована:
  матч хранит seed и снимок характеристик бойцов на момент боя, поэтому повтор показывает именно тот бой,
  даже если бойцы потом изменились.
- **Очки зрелищности** за каждый матч, в окне отчёта после боя видно, откуда они: комбо (2 за каждый удар
  после первого, +5 за 5+ ударов), разнообразие приёмов, спецприёмы, суперы, контр-удары, наказания,
  броски, парирования, оглушение соперника, красование (15) и наказание красующегося (8), быстрый K.O., «перфект», камбэк, фаталити, победа, победа 2:0.
  Зрелищность конвертируется в **славу** (1:1) — основной ресурс для будущих покупок.
- **Награды тура** (после каждого завершённого тура): самый быстрый K.O., больше всего
  комбо, самое разрушительное комбо (по урону), меньше всего полученного урона, самый зрелищный. Каждая награда даёт
  **+30 славы**, около 25 % средних ~118 очков, которые боец получает за матч.
- **Выносливость и мораль** (0–100, старт 100 / 70; `src/tournament/condition.js`). Выносливость сдвигает все шкалы
  «Тела», мораль — все шкалы «Характера». 75 — «в форме», без эффекта. Ниже штраф: при 0 до −1,1 деления
  каждой шкалы группы, больше разницы между самым сильным и самым слабым бойцом. Выше 75 небольшой бонус.
  Замеры зеркальных боёв (`tools/condition.mjs`, по 200 матчей): выносливость 75 против 50 — 67 %, 75 против 25 —
  79 %, 100 против 0 — 94 %; мораль 75 против 50 — 68 %, 75 против 25 — 75 %, 100 против 0 — 90 %.
  - Матч съедает выносливость: 9 + 6 за каждую потерянную полоску здоровья + 3 за третий раунд + 6 за пережитое
    фаталити. Между турами +12 бесплатно.
  - Мораль: победа +9 (2:0 +13), поражение −9 (0:2 −13), «перфект» +3, камбэк +4, своё фаталити +6, чужое −12,
    победа над тем, кто выше в таблице на 3+ места, +6, любовь публики (зрелищность) до +5, награда +4.
    Серия из 3+ поражений («Slump») усиливает падение морали на 50 %. Победа с морали
    ≤ 35 даёт ещё +6 («Redemption»). Истощённый боец (выносливость < 25) теряет 4 морали за матч. Между турами
    мораль на 15 % возвращается к 60.
  - Слава: **Hype** — серия побед с 3-й подряд даёт +5 % славы за каждую победу (3 — +5 %, 4 — +10 %, … максимум +20 %);
    начиная с 3-го тура последние 4 в таблице **на начало тура** — +20 %
    (поддержка аутсайдеров; список фиксируется до первого матча тура и не меняется по ходу тура).
  - **Шанс фаталити** победителя зависит от его морали и выносливости и от боя: сколько здоровья у него осталось к
    FINISH HIM и был ли счёт 2:0 (3–95 %; в турнирах в среднем около 54 %).
  - **Тренировочный лагерь** (кнопка в турнире): за славу — «Rest day» +25 выносливости (75), «Physio» +60 (170),
    «Pep talk» +20 морали (70), «Party with fans» +45 морали, но −10 выносливости (110). У каждого бойца
    автоменеджер: после каждого тура он сам покупает восстановление, держа запас славы (хитрые копят больше).
    Его можно выключить и покупать вручную.
  - Баланс-прогоны полных турниров (`tools/tourney.mjs`, 16 турниров): с автоменеджерами средняя форма держится
    около 78 / 80, на восстановление уходит около трети заработанной славы, разброс мест бойцов на уровне шума.
    Без трат выносливость к 8-му туру падает до 12–20, и команды без управления проигрывают; при разнице формы
    в 30+ очков лучший по форме выигрывает 69–77 % матчей.
  - В отчёте после боя видно, как изменились выносливость и мораль и почему.
- **Прокачка и травмы** (`src/tournament/injuries.js`) — характеристики «плавают» по ходу турнира:
  - **Магазин улучшений** (кнопка ⬆ UPGRADE в лагере): +0,1 деления в любую из 10 шкал. Цена 150 славы и растёт
    на 35 % с каждым уровнем этой шкалы.
  - **Травмы** случаются в бою от сильного удара (50+ урона), супера, броска или контр-удара. Шанс растёт с
    агрессией бьющего и усталостью получающего. Над бойцом появляется «INJURY!» с треском кости, и он сразу
    принимает «побитый» вид, как при критическом здоровье, до конца матча. Нанёсший получает +15 очков зрелищности.
    Не больше одной новой травмы за матч, у одного бойца может быть несколько травм, но разных видов.
  - Каждая травма навсегда отнимает часть шкал и даёт необычный дебафф на 1–3 следующих матча:

    | Травма | Матчей | Дебафф | Навсегда |
    |---|---|---|---|
    | Сломанный нос | 2 | кровоточит в бою (медленно теряет здоровье), −реакция | −стойкость, −реакция |
    | Вывих лодыжки | 3 | не может делать рывки, −подвижность | −подвижность |
    | Трещина в рёбрах | 2 | удары по корпусу наносят ему +25 % урона, −здоровье | −здоровье, −стойкость |
    | Разбитые костяшки | 2 | удары руками наносят −25 % урона | −сила |
    | Сотрясение | 3 | каждый раунд начинает на 40 % оглушённым, оглушается быстрее, −реакция, −комбо | −реакция, −комбо, −хитрость |
    | Надрыв плеча | 1 | шкала супера копится вдвое медленнее, −скорость атаки | −скорость атаки, −сила |
    | Контузия страхом | 2 | робеет: −агрессия, −хитрость | −агрессия, −анти-эйр |

  - Лечение в лагере: −1 тур к сроку травмы за 90 славы (клик по значку травмы).
  - Автоменеджер после восстановления лечит долгие травмы и покупает до двух улучшений за тур:
    хитрые укрепляют сильные стороны, остальные подтягивают слабые.
  - **Баланс:** за турнир среднее значение шкал лиги остаётся прежним. По 16 прогонам: улучшения +9,5 делений на всю
    лигу, травмы −9,6, сдвиг −0,1 % деления (по турнирам от −1,3 до +0,8 %), в среднем 2,6 травмы на бойца за турнир.
    Страховка: травмы бьют сильнее, если лига в целом «перекачалась», и мягче, если ослабла.
- Код: `src/tournament/` (расписание, статистика, очки, сохранение — без DOM, покрыто тестами),
  `src/ui/tournamentScene.js`, `src/ui/spectacle.js`.

## Что реализовано

**Архитектура** (`src/`, ES-модули, без сборки; ~40 файлов, самый большой — художник тела):

| Модуль | Ответственность |
|---|---|
| `core/` | математика, детерминированный ГПСЧ, цикл с фиксированным шагом (60 тиков/с, аккумулятор + интерполяция) |
| `config/` | константы движка и `tuning.js` — глобальные правила боя (гравитация, буфер ввода, скейлинг урона, лимиты жонглирования…) |
| `data/` | **данные**: `moves.js` — фреймдата всех атак, `fighters.js` — 16 бойцов (пропорции, статы, внешность, переопределения атак). Баланс меняется здесь, без правки систем |
| `input/` | клавиатура, буфер ввода (нажатие/удержание/отпускание, направления относительно противника, распознавание движений 236/623/214, двойные нажатия) |
| `anim/` | скелет (FK, 2-костная IK ног, ограничения суставов, центр тяжести), ключевые позы, клипы, аниматор (кроссфейды, контроль скорости суставов, зеркалирование стойки) |
| `physics/` | тело бойца (скорость, ускорение, торможение, гравитация, импульс/масса), пушбоксы и стены, ограничение расстояния, инерция конечностей |
| `combat/` | hurtbox/hitbox из костей, регистрация попаданий, блок, контр-удары, трейды/клэши по приоритету, комбо-защита |
| `fighter/` | машина состояний бойца |
| `game/` | матч: раунды, таймер, KO, слоу-мо KO, рестарт |
| `ai/` | CPU-противник (3 уровня), играет через тот же «сырой» ввод, что и клавиатура |
| `render/` | художник тела, вторичная анимация (волосы, дреды, хвост, полы плащей), арена, эффекты, камера, HUD, отладочный оверлей |
| `audio/` | синтез звуков WebAudio + музыка боя |
| `ui/` | титульный экран (на фоне идёт CPU-бой), выбор бойца, VS-заставка, сцена боя, меню, результаты |

**Ключевой принцип — разделение анимации и правил попадания.** Симуляция каждый тик сэмплирует
позу из клипа, считает скелет и строит hurt/hitbox-капсулы на костях. Рендер берёт ту же позу,
интерполирует между тиками и добавляет *только визуальные* слои (инерция конечностей, волосы,
сплющивание при ударе) — хитбоксы от них не зависят.

**Процедурные бойцы.** 23 сочленения, кости: таз, поясница, грудь, шея, голова, плечи, плечо/предплечье/кисть,
бедро/голень/стопа. Конечности — сегменты с выпуклостями мышц (бицепс, икра, квадрицепс), бесшовные
внутри группы (двухпроходная отрисовка: силуэт-контур + цвет), торс — контур по точкам каркаса,
голова — череп+лицо одним силуэтом, глаза/брови/рот/борода/серьги/причёски, одежда восьми типов,
обувь, перчатки, шляпы (цилиндр с гоглами, поварской колпак), маска ягуара, капюшон. Порядок слоёв
меняется при ударах дальней рукой/ногой (данные атаки), при развороте выполняется «сжатие» по X,
у Whirl Kick — имитация оборота. Смена стойки зеркалит ведущие конечности (и хитбоксы).

**Свет, одежда, мимика.** Ключевой свет задан в мире (сверху слева), поэтому оба бойца освещены с одной
стороны, а контровой свет — смесь неонового цвета бойца и заката арены. Голова отбрасывает тень на шею и
грудь, ближняя рука — на корпус. На сгибах локтей и колен — складки ткани (чем сильнее сгиб, тем их больше),
швы вдоль рукавов и штанин, потёртые колени и локти, складка рубашки, качающаяся с дыханием; всё рисуется
от костей каждый кадр. Мимика: прищур и сжатые зубы при атаке, крик на тяжёлых ударах и спецприёмах,
напряжение в блоке, зажмуренные глаза и гримаса от боли, спирали в глазах при оглушении, крестики при
нокауте, довольные глаза на победе; естественное моргание с неровными интервалами и иногда двойное.

**Анимация.** Idle с дыханием и переносом веса; ходьба вперёд/назад с IK-стопами, фаза шага привязана
к реально пройденному расстоянию (стопы не скользят — проверено тестом); бег; рывок/отскок; присед;
прыжок на месте и сальто вперёд/назад; приземление; LP/HP/LK/HK, апперкот, лоу-кик, подсечка,
2 воздушные атаки, 3 спецприёма; блок высокий/низкий; реакции на удар (голова/корпус/сидя), стаггер,
отбрасывание, жонглирование, нокдаун с отскоком, подъём; головокружение (dizzy); 4 победные позы,
поражение. Каждая атака: замах → ускорение конечности (кривая strike) → контактная поза ровно на
первом активном кадре → удержание → возврат. Тайминг клипа выводится из фреймдаты, поэтому смена
startup/active/recovery в `moves.js` автоматически перестраивает анимацию. Аниматор ограничивает
угловую скорость суставов и скорость таза — без телепортаций.

**Бой.** Startup/active/recovery, урон, стан-урон, hitstun/blockstun, hitstop, высота (mid/low/overhead),
реакция, толчок, параметры подброса, цепочки и окна отмены, жонглирование, приоритет, неуязвимость
по частям тела — для каждой атаки отдельно. Зоны поражения: голова (×1.1 урона), корпус, конечности.
Контр-удар (+урон/+hitstun, тяжёлый — стаггер), «punish», трейды и клэши, отталкивание атакующего
в углу, chip-урон спецприёмов, головокружение по шкале стана. Защита от бесконечных комбо: скейлинг
урона, затухание hitstun, очки жонглирования + усиление гравитации, лимит длины цепочки, лимит повторов
одного приёма, абсолютный кап ударов в комбо.

**Обратная связь.** Hitstop с дрожанием цели, искры/кольца/вспышка контакта (жёлтые на контр-ударе),
щит блока, «разрез воздуха» при промахе, следы быстрых ударов, тряска камеры на сильных ударах,
пыль при прыжках/приземлениях, белая вспышка тела при попадании, KO-слоумо. Арена «Pier 9»
(закат/ночь): небо с солнцем, 2 слоя города с параллаксом, краны, вода с бликами, контейнеры,
мигающая неоновая вывеска, гирлянды, мокрые доски с отражениями, передний план, туман, виньетка.

```bash
npm run audit        # аудит: все пары бойцов CPU vs CPU, проверка что каждая механика реально случается в боях
npm run smoke        # браузерный смоук-тест (нужен Playwright: npm i -D playwright)
```

Покрыто автотестами (все проходят): пол не пробивается ни одной частью тела в боях всех 16 бойцов;
прыжки стабильны (одинаковая высота/время); пушбоксы не пересекаются при сближении, толкании,
в углу и после перепрыгивания; выход из угла; ограничение дистанции; удары регистрируются только
в активные кадры (каждая атака каждого бойца + все попадания в CPU-боях); один удар — одно
попадание; hitstop замораживает обоих; блок высокий/низкий/overhead; блок после смены сторон;
контр-удар; отмена только при контакте; мэш-комбо не зацикливается; лимит жонглирования; все
обычные удары попадают в упор; апперкоты (↓+HP и Skybreaker) попадают по каждому сопернику вплотную и на средней дистанции и сбивают прыжки; каждый удар каждого супера попадает по каждому сопернику; поджог Синдера (тики, 10 с, не добивает); буфер ввода, удержание кнопки не повторяет удар; спецприёмы по
движениям; шкала стана → головокружение; переходы ходьба/присед/прыжок/рывок/бег/блок; смена стойки; нокдаун→подъём;
IK ставит стопы точно; длины костей сохраняются; ограничения суставов; нет скачков поз в анимациях
и в реальных боях; стопы не скользят при ходьбе; KO → следующий раунд → конец матча → рестарт;
победа по времени; тренировка без KO; полные матчи CPU vs CPU для всех бойцов; детерминизм;
**одинаковый результат симуляции при рендеринге 30/60/144 Гц**.

Смоук-тест (выполнялся в headless Chromium): меню → выбор → VS → бой, нажатия клавиш, оверлей,
отсутствие JS-ошибок; стоимость кадра в headless-рендере без GPU ≈ 10 мс (≈ 20 мс с включённым отладочным оверлеем), тик симуляции ≈ 0.04 мс.

## Ограничения и что осталось

* Phaser не используется: Canvas 2D напрямую даёт нужные кривые Безье, градиенты и клиппинг для
  процедурных тел без обёрток; архитектура (сцены, цикл, модули) — эквивалентная.
* Бойцы различаются внешностью, пропорциями, статами и параметрами атак, но анимационный набор и
  список приёмов у всех общий (уникальные спецприёмы для каждого — следующий шаг).
* Нет бросков, снарядов, шкалы «супера», онлайна и геймпада.
* Ограничения скорости в тестах анимации (≤70 px/тик для кистей/стоп, ≤50 для корпуса в атаках) —
  осознанный компромисс для быстрых аркадных ударов; хитбоксы всегда идут по фактической позе.
* Шрифт интерфейса — системный (Arial Black/Impact); на системах без них будет запасной sans-serif.
* Производительность замерялась только в headless Chromium без GPU; на реальном железе не проверялась.
* ИИ простой (реакция с задержкой, блок с вероятностью, анти-эйр, наказание промахов, короткие комбо),
  не учит паттерны игрока.
